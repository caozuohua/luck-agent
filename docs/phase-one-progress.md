- 测试入口增加唯一 JUnit 完成报告检查：退出码 0 但没有完整报告、无测试或报告含失败都不通过。

- 干净 Python 3.12.13 venv 从哈希锁文件安装：53 个包依赖检查通过，完整测试 412 passed / 71 subtests passed。
